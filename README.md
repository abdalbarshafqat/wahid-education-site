# Wahid Education website

Plain HTML site, no build step. Netlify publishes this folder as-is.

- `index.html` Home
- `tutoring.html` Tutoring: free intro, promo, rates, packages
- `programs.html` Community programs
- `books.html` Books (coming soon)
- `about.html` About, mission, contact form
- `thanks.html` Shown after a form is submitted
- `404.html` Shown for a bad link

Forms are handled by Netlify Forms (see the Forms tab in the Netlify site). To edit text, open the page's HTML file and change it in place; every push to `main` deploys automatically once the repo is linked to Netlify.
